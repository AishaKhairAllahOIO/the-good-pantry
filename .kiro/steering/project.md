# The Good Pantry

## Product
The Good Pantry is a small healthy-food e-commerce homepage.
## Stack
- HTML5
- CSS3
- No JavaScript
- No frameworks or external UI libraries

## Design
- Follow `/DESIGN.md` as the visual source of truth.
- Adapt the system to healthy-food e-commerce without changing its core visual language.
- Desktop design first, then responsive adaptation.

## Code
- Use semantic HTML.
- Keep CSS simple, reusable, and organized.
- Prioritize accessibility and performance.
- Do not add features, sections, or dependencies unless requested.

## Agent Behavior
- Make only changes required by the current task.
- Preserve previously approved work.
- Do not redesign approved sections without instruction.
- Keep responses concise.
